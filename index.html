01 / About

Building things that actually run

I am a full-stack developer at WaltWorks, where I have shipped two production platforms for clients since 2025. The first is a suite of eleven serverless Go portals on AWS Lambda for Potatoes South Africa. The second is a PHP platform for SLS Consultants that normalises uses the OpenAI API to automate processing that would otherwise be manual.

I work across the whole stack: database schema and migrations, backend services and APIs, and the front end sitting on top of them. I care about software that holds up in production, because the systems I work on are the ones people use to do their jobs.
